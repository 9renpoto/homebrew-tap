# 9renpoto Tap

## How do I install these formulae?

`brew install 9renpoto/tap/<formula>`

Or `brew tap 9renpoto/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "9renpoto/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
